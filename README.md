# Смачного! — Українська A1–A2

Самостійне тренування української мови для норвезькомовних учнів.
76 завдань, емодзі, українська екранна клавіатура, миттєві пояснення норвезькою.

## Файли

- index.html — увесь урок, стилі та логіка в одному файлі.
- .nojekyll — звичайна статична сторінка.

Розпакуйте архів та завантажте його вміст у корінь потрібного GitHub-репозиторію.
Файл index.html має лежати безпосередньо в папці, з якої публікується сайт.
Публікацію GitHub Pages налаштовуйте в репозиторії за офіційною інструкцією:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Урок не потребує збірки, встановлення бібліотек або зовнішніх ресурсів для роботи.
Для локального використання відкрийте index.html у браузері.

Відповіді зберігаються локально в браузері, якщо він дозволяє localStorage.
Вони не передаються викладачу автоматично. Для надсилання використайте кнопку друку / PDF.
Для редагування змініть index.html. Джерела навчального матеріалу наведено на сторінці.
